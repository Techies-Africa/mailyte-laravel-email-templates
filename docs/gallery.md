# Free Laravel email templates — the whole catalog, in pictures

All 50 free HTML email templates, every layout each one supports, in both light and dark — 294 renders in total. Responsive, dark-mode, WCAG AA, MIT licensed. Nothing to install to look.

Every shot is a real render at 600px wide, taken from the preview gallery that ships with the package, against the sample data in the bundle. Click any template for its full set, the data it expects, and the line of code that sends it.

> Photography in sample data is credited on each template's page and in [CREDITS.md](../CREDITS.md). Shipped defaults never hotlink third-party media.
